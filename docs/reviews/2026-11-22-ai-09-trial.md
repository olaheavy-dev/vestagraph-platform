# AI-09 framework trial: results (LangGraph and Microsoft Agent Framework)

**Date:** 22 Nov 2026 (runs on 21 Nov 2026)  
**Design and plan:** [`2026-11-21-ai-09-trial-design.md`](../superpowers/specs/2026-11-21-ai-09-trial-design.md), [`2026-11-21-ai-09-trial.md`](../superpowers/plans/2026-11-21-ai-09-trial.md)  
**Decides:** AI-04 (the framework), by the founder, from this review.

## In short
Both frameworks ran the same 0064 flow (classifier, single agent, a team of orchestrator, parallel workers, writer and checker) on the same shared prompts, tools, models and caps. On 79 of the 84 scored cases they gave the same outcome, and none of the 5 differences turned out to be a framework difference. Cost and speed are the same. The split is in how the multi-agent work shows in LangSmith traces, where LangGraph gives one clear tree per answer, and in each framework's less mature package (LangGraph's AG-UI adapter is pre-1.0; MAF's Anthropic connector is a beta). **Recommendation: LangGraph, by a narrow margin** (13 to 12 on the scorecard).

## What was run
- A local, throwaway trial project (not pushed): two apps generated from `house-template-fastapi` v0.11.1 (`llm: langchain` and `llm: maf`) and a shared package. Vestagraph data read from a pinned worktree at commit `d8fb6f5`.
- 87 AI-03 cases (set version 3: every chat case except the nine in #373, with the ten comparison cases); rule cases 3 runs each, quality cases once with Claude Sonnet 5.5 as judge.
- Models as 0064: Claude Haiku 5.5 (classifier, single agent, orchestrator, workers), Claude Sonnet 5.5 (writer, checker, judge). Same 13-call cap, history, token limits and settings in both (trial NOTES, settings table).
- Before any paid call: a fresh review found 9 blocking problems (key routing, cost counting under parallel workers, worst-case reservations, a shared spend ledger, fairness of history, call caps and marked text, unscored quality cases, unpinned data); all fixed and re-reviewed. A $0 rehearsal against a local fake Anthropic server then ran the full real path.

## The five differences, explained
- **Three MAF "verdict word" failures** (CHAT-GUARD-VERIFIED-01, CHAT-GUARD-FALSEPOS-01, CHAT-OTHERPLACE-01): each failed on one of three runs, on the single-agent route, where neither flow runs the checker. Two are a gap in the marking code: "nothing" is not on its list of negating words, so "Nothing in the data says … verified" counts as a claim (#380; the same code is in Vestagraph's AI-03 tests). The third ("usually work best") is ordinary wording variation.
- **CHAT-TOOLS-COUNCIL-01** and **CHAT-COMPARE-VERDICT-01:** single quality runs where the judge scored one side a point higher. Run-to-run variation.

## Why LangGraph, and what it doesn't settle
- **For:** the traces show the multi-agent work clearly in LangSmith, the tracing tool 0064 chose, which serves the founder's showcase aim; `langgraph` itself is 1.x and stable; its fan-out to 1 to 3 workers is explicit.
- **Against:** its AG-UI adapter is pre-1.0 (a minor version bump counts as major for merging, 0049); one silent workaround (tagging calls so their words don't leak into the stream).
- **For MAF:** typed hand-offs read well; Microsoft Learn documentation is strong; 0023 had chosen it before 0049 reopened the choice.
- **Against MAF:** a beta Anthropic connector; traces fragmented in LangSmith (possibly the template's set-up rather than MAF itself, issue #142); a fragile counting workaround.
- **Not settled by the trial:** answer quality, which is limited by the shared prompts and tools and needs its own work in the chat's build plan.

## Changes from the design (recorded as they happened)
- **The key:** the founder typed "use ANTHROPIC_API_KEY" (over the earlier "New test key (Recommended)"), so Anthropic's own workspace cap may not have applied; the trial's own counter and ledger held spend to the limit.
- **Tracing:** the EU endpoint refused the LangSmith key (403); the founder chose "Use the US endpoint". Only synthetic test conversations were sent. Real chats still need LangSmith EU (0064).
- **Tools** hide the raw search radius and raw metres (a deviation from TOOLS-07, trial only), and return the display text the data files hold.
- **Fixed replies** (off-topic, verdict) are neutral placeholders in both frameworks; their wording needs the founder's copy review before the chat is built.
- Clocks were measured at the adapter's event stream inside the process, identically for both, not at an external AG-UI client.

- **"Fix the MAF tracing and carry on"** (founder, 21 Nov 2026): the MAF runs used the wrong `LANGSMITH_ENDPOINT` form for MAF, so its traces were lost (404); the setting was fixed and one MAF comparison re-run for its trace only (not scored).
